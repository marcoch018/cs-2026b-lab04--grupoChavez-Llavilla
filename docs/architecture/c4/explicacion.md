BiblioUNSA es una aplicación que usan desde el celular o la computadora los estudiantes y los bibliotecarios de la UNSA. Los estudiantes buscan libros y los reservan; los bibliotecarios registran los préstamos y las devoluciones con el carné QR; y el sistema calcula las multas por retraso. Para entrar usa el correo institucional, y para saber si el estudiante tiene matrícula vigente consulta el Sistema Académico. Avisa por correo cada reserva o multa. Si el Sistema Académico falla, las reservas no se pierden: quedan pendientes y se reintentan.
